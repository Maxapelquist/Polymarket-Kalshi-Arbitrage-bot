  SKAPA NYTT GITHUB-REPO - ENKEL GUIDE
═══════════════════════════════════════════════════════════════

STEG 1: Skapa repo på GitHub
───────────────────────────────────────────────────────────────
1. Gå till: https://github.com/new

2. Fyll i:
   Repository name: Polymarket-Kalshi-Arbitrage-bot
   Description: AI-based event and contract matching system
   Visibility: Private (eller Public)
   
   ⚠️  VIKTIGT: Checka INTE:
   ❌ Add a README file
   ❌ Add .gitignore
   ❌ Choose a license
   
3. Klicka "Create repository"

STEG 2: Kopiera repo URL
───────────────────────────────────────────────────────────────
Efter att repot är skapat, kopiera URL:en som visas.
Exempel: https://github.com/ditt-användarnamn/Polymarket-Kalshi-Arbitrage-bot.git

STEG 3: Kör dessa kommandon i terminalen
───────────────────────────────────────────────────────────────

# Ta bort gamla remote
git remote remove origin

# Lägg till ny remote (ersätt med din URL från steg 2)
git remote add origin https://github.com/DITT_ANVÄNDARNAMN/Polymarket-Kalshi-Arbitrage-bot.git

# Stage alla ändringar
git add -A

# Commit
git commit -m "Initial commit: LLM-driven event matching pipeline"

# Push till nytt repo
git push -u origin raw-api-rebuild

# ELLER skapa main branch:
git checkout -b main
git push -u origin main
